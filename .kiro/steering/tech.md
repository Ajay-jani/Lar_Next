# Technology Stack

## Framework & Runtime
- **Next.js** - React framework with SSR/SSG capabilities
- **React** - Component-based UI library
- **Node.js** - JavaScript runtime environment

## Build System
- **Next.js built-in bundler** - Webpack-based with optimizations
- **TypeScript** - Type-safe JavaScript (recommended)
- **ESLint** - Code linting and formatting

## Package Management
- **npm** or **yarn** - Dependency management

## Common Commands

### Development
```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run start        # Start production server
npm run lint         # Run ESLint
npm run type-check   # TypeScript type checking
```

### Testing
```bash
npm test             # Run test suite
npm run test:watch   # Run tests in watch mode
npm run test:coverage # Generate coverage report
```

## Recommended Libraries
- **Tailwind CSS** - Utility-first CSS framework
- **Next.js Image** - Optimized image component
- **React Hook Form** - Form handling
- **SWR** or **React Query** - Data fetching
- **Prisma** - Database ORM (if using database)
